# OpenMT2

Open-source, re-implementation of the Metin2 old sources, with the
proprietary runtime dependencies replaced by open-source equivalents.

The goal of OpenMT2 is providing a fresh new set of files and tools to build, run, and experiment
with metin2 development, this organization do not provide assets other than code.

**Documentation, specifications and project status are accessible through <https://open-mt2.github.io/docs/>**

## Repositories

| Repository | Purpose |
| :--- | :--- |
| [`client`](https://github.com/open-mt2/client) | OpenMT2 Client executable |
| [`neoeter`](https://github.com/open-mt2/neoeter) | OpenMT2 Engine: platform, IO, image, render, audio, model, terrain and effects |
| [`neoeter-csharp`](https://github.com/open-mt2/neoeter-csharp) | CSharp bindings & Framwork for server/client packs |
| [`neoeter-python`](https://github.com/open-mt2/neoeter-python) | Embedded CPython 2.7 host and Python bindings |
| [`devkit`](https://github.com/open-mt2/devkit) | Docker devkit image for client build dependencies |
| [`speedtreebkr`](https://github.com/open-mt2/speedtreebkr) | Speedtree geometry baker |
| [`docs`](https://github.com/open-mt2/docs) | Documentation of OpenMT2 projects |

## Disclaimer

Every sources in this organization are not production ready, use them at your own risk for building public servers.
It's at a very experimental state, shipped with bugs are probably security vulnerabilities.
